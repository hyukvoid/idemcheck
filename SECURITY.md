# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

1. Preferred: use GitHub's private vulnerability reporting — open the
   repository's **Security** tab and choose **Report a vulnerability**.
2. If that option is not available to your GitHub account, contact the
   maintainer through GitHub ([@hyukvoid](https://github.com/hyukvoid)) to
   arrange a private channel before sharing details.

When reporting, include the affected version (`idemcheck version`), steps to
reproduce, and the potential impact.

## Scope

In scope: the `idemcheck` CLI and this repository's build and release
automation.

Out of scope: the demo services under `examples/` (deliberately unsafe
teaching code) and the systems you point IdemCheck at.
